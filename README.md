# 🫡 Seems Goals Tracker

Personal goal tracking app with calendar, progress tracking, and accountability system.

## Features
- **6 Goals:** Fitness, Nutrition, Career, Social, Organization, Travel
- **Progress tracking** with milestones and streaks
- **Calendar** for events and planning
- **Daily check-ins** with meal logging and priorities
- **History** of all activities and progress
